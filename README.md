# Vocal Trainer v0.5.1 — вокальная лаборатория

Локальное Windows-приложение на **.NET 10 / WPF / MVVM** для тренировки интонации, слуха и ведения журналов занятий. Интерфейс на русском, ноты показаны латинскими и русскими названиями (`C3 — До (малая октава)`).

Всё работает на ПК, без аккаунта и отправки голоса в облако. **Аудио не сохраняется автоматически.** Только отдельная кнопка «Записать WAV» создаёт звуковой файл.

## План развития и текущий этап

Зафиксирована [дорожная карта v0.5.1 → v1.0](docs/ROADMAP.md): стабилизация → экспорт занятий → персональный тренер → музыкальные навыки → вокальный анализ → работа с песнями → полноценный релиз.

Сейчас идёт фактическое тестирование **v0.5.1**. До полного занятия 10–15 минут с реальным микрофоном и корректным итоговым логом этап остаётся открытым; приоритет — проверки и исправления. [Ручной протокол](docs/TESTING-v0.5.1.md) и [правила разработки и выпуска](docs/DEVELOPMENT.md) определяют порядок дальнейшей работы.

1. Установи [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) на Windows 10/11.
2. Клонируй [репозиторий](https://github.com/Exelsioro/VocalTrainer) командой `git clone https://github.com/Exelsioro/VocalTrainer.git` или распакуй ZIP исходников; открой PowerShell в папке `VocalTrainer`.
3. Запусти:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1 -SelfContained
   ```

4. После успешной проверки и сборки открой `dist\Release\VocalTrainer.exe`.

Без параметра `-SelfContained` потребуется .NET 10 Desktop Runtime. Параметры: `-SkipTests`, `-Runtime win-arm64` (для Windows ARM).

В `dist` хранятся только последние `Release` и, при необходимости, `Debug` (`-Configuration Debug`). ZIP автоматически не создаётся. Только для явно запрошенного пакета используй `-Package`: архив попадёт в `artifacts\packages`. Скриншоты и логи проверок хранятся вне `dist`.

Пройдены алгоритмические тесты и проверка запуска, привязок данных, отрисовки всех шести вкладок и закрытия WPF. `build.ps1` выполняет обе группы тестов перед публикацией. ## Новое в 0.5.1 — управление и пауза

- Горячие клавиши для упражнений, слуховых тестов, MIDI, микрофона, ручной WAV-записи, импорта и сохранения JSON.
- **Space** в JSON-упражнении и MIDI управляет паузой/продолжением; время паузы исключается из оценки, MIDI-эталон временно замолкает.
- **R** повторяет текущую ноту JSON-упражнения (или целиком выбранный MIDI-фрагмент); **N** пропускает ноту; **Esc** останавливает активный режим.
- **Ctrl+1…6** — тюнер, упражнения, слух, диапазон, редактор и MIDI, **F1** — настройки. Комбинации можно переназначать в интерфейсе; конфликтующие назначения запрещены. При редактировании текста одиночные клавиши не перехватываются.
- Конфигурация хранится в `%LOCALAPPDATA%\VocalTrainer\settings.json`, меняется только по явному действию. Аудио по-прежнему не сохраняется автоматически.
- Список клавиш, поведение повтора и проверки: **[docs/SHORTCUTS.md](docs/SHORTCUTS.md)**.

## Новое в 0.5 — MIDI-мелодии

Вкладка **«Мелодии · MIDI»** позволяет тренировать вокальные партии из стандартных MIDI-файлов (форматы 0 и 1; .mid / .midi):

1. Импортируй MIDI с отдельной **вокальной или монофонической** дорожкой. В комплекте есть `midi/demo-vocal-melody.mid` (8 нот с изменением темпа).
2. Выбери дорожку. Приложение показывает, сколько нот она содержит, и сообщает о перекрытиях (полифонии). Если дорожка содержит аккорды, в качестве подсказки берётся **самая высокая звучащая нота**. Для точных занятий лучше пользоваться отдельным вокальным MIDI.
3. Укажи скорость **50–150%**, начало и конец фрагмента **в секундах исходного MIDI**, количество повторов **1–10**. Нажми «Применить фрагмент». Для переноса всей выбранной партии введи целое число в «Сдвиг, полутоны» (например `+3`, `-5`, `-12`) и нажми «Применить сдвиг всей партии». Допустимые границы рассчитываются по всем нотам дорожки; доступны кнопки на полутон вверх/вниз и возврат к оригиналу.
4. Нажми «Прослушать эталон» — приложение воспроизведёт выбранные ноты отдельными синусоидальными звуками, с учётом смен темпа, пауз, скорости, транспонирования и повторов. Это **не** воспроизведение инструментов или исходной фонограммы.
5. Чтобы спеть, сначала запусти микрофон на вкладке «Тренажёр», затем вернись в MIDI и нажми «Начать практику». После трёхсекундного отсчёта появится маркер времени. По умолчанию практика идёт без подложки; галочка «Петь вместе с эталоном» включает совместный режим. В нём нужны наушники.
6. Синие сегменты — целевые ноты; поверх них рисуется реальная высота голоса: зелёная в пределах ±40 центов, оранжевая при отклонении. Тишина разрывает линию, ошибки на октаву остаются видимыми. Белый маркер показывает текущее время. Для длинных песен доступны окно 10–60 секунд, автослежение и ручная прокрутка. После занятия появится сводка, а линия останется для просмотра.
7. Нажми «Стоп» для досрочного завершения и сохранения частичного результата.

Подробная инструкция: [практика песни, график исполнения и транспозиция](docs/MIDI-PRACTICE.md).

**Оценка MIDI-практики:** по каждой звучащей целевой ноте ведётся количество отсчётов, количество достоверных голосовых отсчётов, доля попаданий в пределах ±40 центов и средняя абсолютная ошибка. Для зачёта нужно не менее 55% отсчётов с обнаруженным голосом и 75% точных отсчётов (минимум два достоверных). Сводка учитывает и ноты, по которым голос отсутствовал. Это **техническая оценка высоты**, не оценка тембра, ритмической выразительности или безопасной вокальной техники.

**Ограничения MIDI:** PPQ-тайминг (SMPTE не поддерживается); формат 2 не поддерживается; глиссандо/pitch bend, sustain-педаль, выражение, динамика, пословная разметка и вокальные украшения не импортируются. Если несколько нот играют одновременно, берётся верхняя; ритмические паузы сохраняются. Пение оценивается относительно выбранной партии, а не звучащего MP3. Маленькие по длительности ноты могут оцениваться грубо из-за частоты обновления микрофона (~8 раз/с). Для надёжной проверки выбирай относительно протяжные вокальные фразы.

**Логи:** `practice-YYYYMMDD.jsonl` содержит `midi_import`, `midi_fragment_prepared`, `midi_practice_start`, `midi_pitch_sample`, `midi_practice_end`. Обычная практика не создаёт звуковых файлов. Числовые данные и имена импортированных MIDI-файлов сохраняются локально. При нескольких повторах статистика по каждой ноте агрегируется по всем циклам; на графике текущий цикл рисуется отдельно.

## Функции из 0.4

### 1. Слух · интервалы

- Выбор опорной ноты в диапазоне C2–C6 с русским и латинским названием.
- Интервал: 1, 2, 3, 4, 5, 7 или 12 полутонов.
- Два звука подряд, без указания правильного ответа до попытки.
- Ответ: «Ниже», «Одинаково», «Выше»; повтор пары доступен до ответа.
- Результат и правильная последовательность нот появляются после ответа.
- Опциональная адаптивность: 3 правильных ответа подряд уменьшают интервал на ступень из списка; 2 ошибки подряд увеличивают. Равные ноты также могут входить в тест; эта простая адаптация не является полной моделью прогресса.
- Логи вопросов и ответов в JSONL; микрофон для слухового теста не нужен.

### 2. Диапазон · диагностика

1. На вкладке «Тренажёр» выбери микрофон, включи мониторинг и при необходимости откалибруй порог шума.
2. На вкладке «Диапазон» выбери интересующую ноту в диапазоне C2–C6. Ноты ниже и выше диапазона детектора не измеряются.
3. Послушай 2-секундный эталон, затем нажми «Измерить голос» и спой выбранную ноту примерно 3,5 секунды.
4. Приложение рассчитает медианное отклонение в центах, процент кадров с достоверной высотой и медианное абсолютное отклонение (показатель разброса).
5. Отдельно отметь собственные ощущения: комфортно, неустойчиво/трудно или неприятные ощущения/напряжение. Без этой оценки результат в карту не добавляется.

Карта сохраняется между запусками в `%LOCALAPPDATA%\VocalTrainer\range-history.json`; детали дополнительно пишутся в JSONL. Алгоритм **не определяет здоровье голоса, голосовой тип и безопасность исполнения**. Не пытайся взять предельные ноты. При боли, жжении или осиплости прекращай занятие.

### 3. Редактор упражнений

- Создание нового упражнения, открытие существующего JSON, редактирование названия, описания, целей и задач.
- Добавление, удаление и изменение порядка секций и нот.
- Настройка каждой ноты: `note`, `previewSeconds`, `holdSeconds`, `transitionSeconds`, а также необязательных `toleranceCents`, `requiredAccuracy`, `maxAttempts`, `autoRepeatOnFail`.
- Проверка на соответствие исходной `schemaVersion = 1` перед сохранением; редактор сохраняет в отдельный путь через системный диалог, затем загружает созданное упражнение в основной тренажёр.
- Если редактируешь значение в таблице, **нажми Tab или заверши редактирование ячейки**, затем сохраняй.

Совместим с упражнениями из версий 0.1–0.3. Старые поля не переименовывались.

## Основной тренажёр (унаследован из 0.3)

- Выбор ноты MIDI 0–127 (воспроизведение) и длительности эталона 0,2–30 секунд.
- Низкоуровневый YIN-подобный анализ основного тона с микрофона в памяти, ~8 обновлений в секунду (рабочий диапазон 65–1100 Гц).
- Тюнер отклонения в центах и график последних 30 секунд.
- Калибровка уровня шума в тишине.
- Три режима обратной связи: live, на слух, контрольный.
- Оценка попытки по точности, времени поиска ноты и устойчивости; автоматический повтор неудачных нот.
- Импорт и выполнение JSON-упражнений по секциям.
- Опциональная ручная запись WAV отдельной кнопкой.

Используй **наушники**, чтобы эталон не попадал в микрофон и не портил измерения.

## Формат упражнения JSON

```json
{
  "schemaVersion": 1,
  "title": "Первые две ноты",
  "description": "Лёгкое удержание",
  "goals": ["Попадание в ноту"],
  "tasks": ["Петь без напряжения"],
  "sections": [
    {
      "title": "Разминка",
      "description": "Спокойная громкость",
      "notes": [
        {
          "note": "C3",
          "previewSeconds": 2,
          "holdSeconds": 3,
          "transitionSeconds": 2,
          "toleranceCents": 40,
          "requiredAccuracy": 0.75,
          "maxAttempts": 2,
          "autoRepeatOnFail": true
        },
        {
          "note": "D3",
          "previewSeconds": 2,
          "holdSeconds": 3,
          "transitionSeconds": 2
        }
      ]
    }
  ]
}
```

В `exercises/` есть несколько готовых примеров. Полная JSON Schema — `docs/exercise.schema.json`. Допустимые форматы нот: `C3`, `F#4`, `Bb3`, `Db4`, `C-1` и т. д. Октавы соответствуют scientific pitch notation: `C4 = 261,63 Гц`, `C3 = 130,81 Гц`.

## Какие файлы создаются

| Путь | Содержимое |
|---|---|
| `%LOCALAPPDATA%\VocalTrainer\Logs\session-*.jsonl` | Сессии, телеметрия и результаты упражнений |
| `%LOCALAPPDATA%\VocalTrainer\Logs\practice-YYYYMMDD.jsonl` | Тесты слуха, оценки диапазона, сохранение упражнений, **MIDI-практика** |
| `%LOCALAPPDATA%\VocalTrainer\range-history.json` | Сводная карта нот между запусками |
| `%LOCALAPPDATA%\VocalTrainer\Recordings\voice-*.wav` | **Только** при ручном нажатии «Записать WAV» |
| `%LOCALAPPDATA%\VocalTrainer\Exercises\*.json` | Созданные упражнения, если выбран каталог по умолчанию |

Никаких WAV для мониторинга, слуховых тестов, диагностики диапазона или упражнений по умолчанию не создаётся. Перед отправкой логов проверь текстовые заметки пользователя: они включаются в JSONL.

## Ограничения

В v0.5 тренировка слуха — это **сравнение пары звуков**, а не произнесение интервала голосом. Диагностика диапазона — ручная проверка по одной ноте, не автоматическое определение баса/баритона/тенора. Визуальный редактор не является MIDI-секвенсором; он редактирует прежнюю JSON-модель. Импорт **MP3/WAV и автоматическое извлечение вокальных партий** не реализованы; для мелодий нужен заранее подготовленный MIDI. На MIDI-графике доступны масштаб по времени и прокрутка; анализ ритмических атак на уровне слогов пока отсутствует. Точность сопоставления при высокой задержке микрофона ограничена.
