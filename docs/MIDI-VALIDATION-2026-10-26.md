# Проверка MIDI-тренажёра · 26.10.2026

Собрана автономная Release-версия Windows x64 с графиком исполнения поверх эталона, прокруткой и числовым сдвигом всей выбранной партии. Версия приложения — 0.5.1, пробное обновление MIDI.

## Проверки

Пройдены **222 проверки**: 212 алгоритмических и 10 WPF. Логи: `midi-algorithm-tests.log`, `midi-wpf-tests.log`. Публикация: `midi-publish.log`. Компиляция и публикация прошли без предупреждений и ошибок.

Проверены сдвиги вверх и вниз, в том числе более октавы, сохранение времени нот, прослушивание новой высоты, отказ недопустимых значений без изменения применённой партии, ограничения по всей дорожке и блокировка изменения во время попытки. Проверены тишина, разрывы, одиночные измерения, большие отклонения голоса, просмотр длинной песни и сохранение исполненной линии после остановки.

Интеграционная проверка WPF вводит сдвиг через поле и кнопку интерфейса, прокручивает график, запускает отсчёт, передаёт имитированные частоты и тишину в модель практики, проверяет привязку к Piano Roll и наличие зелёных/оранжевых пикселей в отрисованном изображении. Непроверенный реальный микрофон не подменяется этим результатом.

Отрисовки находятся в `dist/midi-preview-20261026`. Проверочные ноты и голосовые данные существуют только в тесте и не сохраняются в историю пользователя.

## Дистрибутив

`dist/VocalTrainer-0.5.1-midi-win-x64-20261026.zip` содержит приложение, примеры JSON/MIDI, краткую и подробную инструкции. Предыдущие дистрибутивы сохранены отдельно. Настройки и личные записи в пакет не включаются.

ZIP распакован в отдельный каталог: проверены 10 файлов и SHA-256 EXE, приложение запущено из распакованной папки, окно отвечает, штатное закрытие завершилось с кодом 0. Лог: `midi-launch.log`. SHA-256 архива: `7162C73F0DC2C9AEBA08E038C6D145A03137AAAEC522CADE9F645860F6476237`.

Публикация выполнена из PowerShell:

```powershell
dotnet publish src/VocalTrainer/VocalTrainer.csproj -c Release -r win-x64 --self-contained true -o dist/VocalTrainer-0.5.1-midi-win-x64-20261026 -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -p:UseSharedCompilation=false -m:1
```

В проверочной среде использован кеш NuGet; сетевой аудит пакетов отключён только для процесса сборки. Реальное оборудование, компенсация аппаратной задержки и педагогическая оценка остаются предметом ручного тестирования.
