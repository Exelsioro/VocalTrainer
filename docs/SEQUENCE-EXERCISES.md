# Повтори последовательность

На вкладке «Упражнения» выбери JSON и тип «Повтори последовательность». Каждая секция становится отдельной фразой. Галочка «Проиграть эталон» включает прослушивание всей фразы до исполнения; её можно снять для пения по памяти или по нотам.

После эталона идут три секунды подготовки. Затем пой всю фразу по движущемуся маркеру. Ноты оцениваются в заданные интервалы времени: пропуск не сдвигает остальные ноты, одинаковые ноты подряд проверяются отдельно. Для каждой ноты результат показывает точность, покрытие голосом и среднюю ошибку в центах; подробные измерения и итоги записываются в JSONL. Для зачёта фразы должны быть зачтены все её ноты.

Над программой остаётся тюнер со шкалой и графиком последних 30 секунд. Для фразы дополнительно показаны эталонные ноты и линия исполненного голоса. Цвет соответствует допуску текущей ноты; тишина разрывает линию. Режимы скрытой обратной связи сохраняют свои правила: «на слух» скрывает голос во время исполнения, «контрольный» открывает результаты после упражнения.

Space ставит на паузу эталон, отсчёт или исполнение; пауза не входит в оценку. R начинает фразу заново, N пропускает всю текущую секцию, Esc останавливает упражнение. Автоповтор повторяет целую фразу по общим настройкам вкладки. Индивидуальные `maxAttempts` и `autoRepeatOnFail` используются в режиме отдельных нот; допуск и требуемая точность каждой ноты действуют в обоих режимах.

В конструкторе выбери тип упражнения и включи или выключи эталон перед сохранением JSON. Для последовательности `holdSeconds` («Пение, с») задаёт длительность каждой ноты и в эталоне, и при исполнении, `transitionSeconds` («Пауза, с») — промежуток до следующей. `previewSeconds` относится к режиму отдельных нот. Последняя пауза секции служит отдыхом перед автоматическим повтором.

```json
{
  "schemaVersion": 1,
  "mode": "sequence",
  "playReference": true,
  "title": "Повтори До — Ре",
  "sections": [{
    "title": "Первая фраза",
    "notes": [
      { "note": "C3", "previewSeconds": 1, "holdSeconds": 1.5, "transitionSeconds": 0.3 },
      { "note": "D3", "previewSeconds": 1, "holdSeconds": 1.5, "transitionSeconds": 1 }
    ]
  }]
}
```

Старые JSON без новых полей работают как прежде: `mode = "notes"`, `playReference = true`. Пример в комплекте — `exercises/repeat-sequence.json`. Изменение типа и галочки на вкладке практики действует до выбора другого упражнения; для сохранения параметров в файле используй конструктор.

Проценты основаны на достоверных измерениях микрофона; это оценка высоты и её попадания в заданные временные окна. Автоматического подстраивания сетки под свободный темп исполнения пока нет. Голос в WAV автоматически не записывается.
