# Дорожная карта Vocal Trainer · v0.5.1 → v1.0

Зафиксировано: 24.10.2026. Текущая версия приложения: **v0.5.1, интеграционное тестирование**.

## Цель

Десктопное приложение на .NET, которое помогает самостоятельно учиться петь: проводит занятия, измеряет результат, показывает прогресс и адаптирует программу обучения. Основное направление — чистый вокал; развитие рок- и метал-техники рассматривается в дальнейшем. Акустические метрики не подтверждают безопасность вокальной техники.

Этапы упорядочены по зависимостям. Календарные сроки пока не назначены. Переход к следующей версии требует выполнения критериев завершения предыдущей; исправления, необходимые для прохождения текущего этапа, выполняются сразу.

## Состояние на 27.10.2026

- Release-сборка, автономный EXE и ZIP для Windows x64 созданы; EXE запущен и штатно закрыт.
- Пройдены 340 автоматических проверок: алгоритмы, MIDI, библиотека песен, повтор фраз, экспорт, загрузка, привязки и отрисовка семи вкладок WPF. Результаты текущей сборки: [EXPORT-VALIDATION.md](EXPORT-VALIDATION.md).
- `VocalTrainer.sln` присутствует в корне. Сборка из интерфейса Visual Studio отдельно не проверена.
- Микрофон, физическое воспроизведение, ручная WAV-запись, длительное занятие и поведение при аварийном завершении ещё требуют ручной проверки.
- Git подключён к [Exelsioro/VocalTrainer](https://github.com/Exelsioro/VocalTrainer); GitHub Actions ещё не настроен.
- Реализован ZIP-экспорт схемы 1.0.0. SQLite, отдельная DSP-библиотека и персональные планы ещё не реализованы. Оценки по времени и компенсация задержек остаются задачами стабилизации.

Отчёт о выполненной проверке: [BUILD-VALIDATION.md](BUILD-VALIDATION.md). Протокол следующей проверки: [TESTING-v0.5.1.md](TESTING-v0.5.1.md).

## v0.5.1 — фактическое тестирование

Критерии этапа остаются открытыми. По последующим запросам добавлены отдельные функции следующих этапов; это не означает завершения интеграционного тестирования или стабилизации.

Проверить `build.ps1` и Visual Studio, запуск и закрытие, обнаружение и остановку микрофона, точность определения нот, независимое воспроизведение эталона и WAV-запись по явному действию. Проверить загрузку и полное выполнение JSON-упражнений, паузу, пропуск, повтор и горячие клавиши; импорт MIDI, эталон и практику голосом; итоговые логи и последствия аварийного завершения.

**Критерий завершения:** одно полное занятие 10–15 минут без критических ошибок, с корректным итоговым логом и заполненным [протоколом](TESTING-v0.5.1.md). Автоматические проверки сами по себе не закрывают этот этап.

## v0.5.2 — техническая стабилизация

Крупное внутреннее обновление без обязательного добавления пользовательских функций.

| Направление | Задачи |
| --- | --- |
| Аудиодвижок | Устройства, буферы, задержки, безопасные старт и стоп, освобождение ресурсов, потеря устройства |
| Pitch detection | Проверка YIN на синтетических и контрольных сигналах, шум, гармоники и ошибки октавы |
| Оценка нот | Временные метрики вместо зависимости результата от числа UI-кадров; явные правила учёта тишины и недостоверного тона |
| Синхронизация | Измерение и компенсация задержек воспроизведения, записи и анализа; единая монотонная временная шкала |
| Архитектура | Поэтапное отделение аудиотракта, DSP, сценариев упражнений, хранения и представления |
| Тестирование | Unit- и интеграционные проверки, регрессии основных режимов, автоматическая Windows-сборка |
| Надёжность | Обработка исключений, восстановление настроек, диагностика ошибок, повреждённые и незавершённые логи |
| Git и CI | Репозиторий Git; GitHub Actions для сборки, тестов, проверки состава ZIP и запуска опубликованного EXE |

Изменение метрик сопровождается версией алгоритма и тестами, позволяющими объяснить разницу между старой и новой оценкой. Допуски для детектора и задержек фиксируются в тестовом наборе до принятия изменений.

**Критерий завершения:** воспроизводимые измерения на контрольных сигналах, воспроизводимая сборка из чистого checkout, успешный Windows CI и отсутствие критических дефектов в основных сценариях. Изменения MIDI не нарушают обычный тюнер и JSON-практику.

## v0.5.3 — экспорт занятий для анализа

Создать единый переносимый отчёт для количественного разбора занятия и подготовки следующего JSON-упражнения.

Реализованный состав архива:

```text
VocalTrainer_Session_2026-10-24.zip
├── manifest.json
├── session.json
├── pitch.csv
├── attempts.json
├── range.json
├── progress.json
├── diagnostics.json
└── README.txt
```

Реализован формат `VocalTrainer.Session` 1.0.0. Точные столбцы, правила оценивания, настройки приватности и совместимость описаны в [SESSION-EXPORT.md](SESSION-EXPORT.md). Сквозной разбор реального занятия и создание следующего упражнения ещё требуют пользовательской проверки.

| Файл | Содержимое |
| --- | --- |
| `manifest.json` | Версия схемы, версия приложения, идентификатор занятия, время экспорта и перечень файлов |
| `session.json` | Режимы, упражнение или MIDI-фрагмент, целевые параметры, начало, длительность, паузы и статус завершения |
| `pitch.csv` | Временные отметки, целевые ноты и частоты, распознанные частоты, центы, достоверность и отсутствие сигнала |
| `attempts.json` | Успешность, временная точность, покрытие голосом, время поиска ноты, устойчивость и повторные попытки |
| `range.json` | Измерения диапазона и отдельные субъективные оценки комфорта |
| `progress.json` | Сопоставимые изменения по занятиям с указанием версии оценивания |
| `diagnostics.json` | Аудиоустройство, частота дискретизации, настройки анализа, задержки и ошибки |

Требования: явные единицы измерения, UTC для абсолютного времени, монотонное относительное время, документированный учёт пауз и пропусков, отличимость отсутствия данных от нулевого результата. Изменения схемы версионируются; старые экспорты остаются читаемыми либо мигрируются. Заметки пользователя и сведения об устройстве видны в составе экспорта до передачи. Аудио по умолчанию не включается.

**Критерий завершения:** одного ZIP достаточно для количественного анализа занятия и создания следующего совместимого JSON-упражнения без обязательной аудиозаписи. Проверены полный и прерванный сеансы, отсутствие голоса и загрузка предыдущей версии формата. Выводы о тембре и технике ограничены реально экспортируемыми измерениями.

## v0.6 — персональный тренер

Профиль учащегося, история тренировок, карта освоенных нот, локальное хранение истории в SQLite и генерация индивидуального плана.

Цикл: результаты прошлых занятий → оценка сильных и слабых навыков → план следующего занятия → тренировка → обновление прогресса.

Начальная адаптация основана на прозрачных правилах. Каждая рекомендация связана с конкретными результатами; встроенная LLM не является зависимостью этого этапа.

**Критерий завершения:** несколько последовательных занятий меняют персональный план по документированным правилам; пользователь видит причину изменения, а история сохраняется между запусками.

## v0.7 — музыкальные навыки

Метроном, ритмическая точность, интервалы голосом, музыкальная память и повторение коротких мелодических фраз. Генератор упражнений учитывает сложность, диапазон, длину последовательности, разрешённые интервалы и темп.

**Критерий завершения:** упражнения генерируются в заданных пределах, ритм и высота оцениваются раздельно, результаты входят в историю и персональный план.

## v0.8 — продвинутый вокальный анализ

Относительная громкость и динамика, начало звука, устойчивость вибрато, плавность соединения нот, устойчивость фраз, спектральные изменения и наблюдения за переходами регистров. Без калибровки микрофона уровень не представляется как абсолютная громкость в дБ SPL.

**Критерий завершения:** каждая новая метрика имеет описание, проверочный набор сигналов и ограничения достоверности. Акустические признаки не используются для автоматического заключения о безопасности, здоровье голоса или правильности техники.

## v0.9 — работа с песнями

MusicXML, улучшенный Piano Roll, привязка текста к нотам, редактор вокальных партий и занятия по отдельным фрагментам. Развить имеющиеся скорость и транспозицию MIDI. Для поддерживаемой аудиоподложки предусмотреть замедление без изменения высоты и отдельное управление транспозицией.

Автоматическая транскрипция вокальной мелодии из аудио — отдельное исследовательское направление; она не является обязательным условием v1.0.

**Критерий завершения:** композиция импортируется в рамках документированного подмножества MusicXML, текст и партия редактируются, фрагменты повторяются с выбранными параметрами и оцениваются без потери синхронизации.

## v1.0 — полноценный релиз

Связать профиль, обучение, практику, историю, адаптацию, работу с композициями и экспорт в единый пользовательский путь. Завершить UX, сообщения об ошибках, документацию и поставку Windows-дистрибутива.

**Критерий завершения:** пользователь самостоятельно проходит путь от первого запуска до серии занятий и разбора прогресса; автоматические и ручные проверки пройдены, критических дефектов нет, миграции данных и установка на чистой Windows проверены. Поддерживаемые архитектуры и ограничения явно перечислены в релизе.
