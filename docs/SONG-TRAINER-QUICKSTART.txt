VOCAL TRAINER 0.5.1 — ОБНОВЛЕНИЕ ТРЕНАЖЁРА ПЕСЕН
26.10.2026 · Windows x64 · Self-contained Release

Распакуйте ZIP целиком и откройте VocalTrainer.exe.
Устанавливать .NET отдельно не требуется.

УПРАЖНЕНИЯ
Перейдите на отдельную вкладку «Упражнения». Загруженные JSON выбираются
из выпадающего списка. Импорт добавляет файл в библиотеку, редактор
позволяет создавать новые. Список импортированных путей запоминается
между запусками; сами исходные файлы нужно сохранять по прежним путям.
Микрофон включается на вкладке «Тренажёр» либо Ctrl+M.

ПЕСНЯ И ТЕКСТ
На вкладке «Мелодии · MIDI» импортируйте midi/demo-with-lyrics.mid.
В нём уже есть демонстрационный текст. Он подсвечивается по строкам
при прослушивании и практике. Можно импортировать LRC или TXT:
для TXT укажите время строк и нажмите «Применить разметку».
Кнопка «Строка начинается сейчас» помогает разметить текст на слух.
«Сохранить LRC» сохраняет результат для повторного использования.
Для отдельной фразы выберите строку и нажмите
«Выбрать строку как фрагмент», затем начните практику.

НОТЫ И ОКТАВЫ
Под настройками MIDI показаны диапазон и список октав. Раскройте
«Ноты, октавы и частоты эталона» для таблицы высот и длительностей.
Сдвиг всей партии задаётся в полутонах: +3 — выше, -12 — ниже на октаву.
После ввода нажмите «Применить сдвиг всей партии».

СОВМЕСТНОЕ ПЕНИЕ
Включите микрофон и отметьте «Петь вместе с эталоном».
Используйте наушники, чтобы микрофон не захватывал звук из колонок.
Нажмите «Начать практику»: после отсчёта звучит MIDI-эталон,
а ваш голос отображается поверх нот. Зелёный — попадание ±40 центов,
оранжевый — отклонение, тишина — разрыв линии.
Space — пауза, R — повтор фрагмента, Esc — остановка.
Без галочки совместного пения практика проходит без подложки.

Ctrl+1 — тюнер, Ctrl+2 — упражнения, Ctrl+3 — слух,
Ctrl+4 — диапазон, Ctrl+5 — редактор, Ctrl+6 — MIDI, F1 — настройки.

Текст следует за скоростью, фрагментом, паузами и повторами.
Обычная практика сохраняет числовые логи. Аудио записывается
только после отдельного нажатия «Записать WAV».

Это пробная версия; реальное оборудование проверяется отдельно.
Подробности: LYRICS-AND-EXERCISES.md и MIDI-PRACTICE.md.
