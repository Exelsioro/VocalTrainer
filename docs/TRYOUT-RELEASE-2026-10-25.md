## Команды сборки

Обе тестовые программы выполнены через `dotnet run --configuration Release`. Публикация выполнена из PowerShell в отдельный каталог, чтобы не заменять прежние EXE:

```powershell
dotnet publish src/VocalTrainer/VocalTrainer.csproj --configuration Release --runtime win-x64 --self-contained true --output dist/VocalTrainer-0.5.1-preview-win-x64-20261025 -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -p:UseSharedCompilation=false -m:1
```

После публикации добавлены материалы для преподавателя из `TRYOUT-RU.txt`, `TRYOUT-FEEDBACK-RU.txt` и `SHORTCUTS.md`, сведения о сборке с хешем EXE; папка упакована PowerShell-командой `Compress-Archive`. Рядом с ZIP сохранён файл `.sha256`.
