# Библиотека песен

На вкладке «Мелодии · MIDI» нажми «Импорт MIDI». Файл автоматически копируется в библиотеку и появляется в выпадающем списке «Библиотека песен». Выбери песню в этом списке, чтобы открыть её снова. При перезапуске открывается последняя выбранная песня.

Импортируй LRC/TXT в разделе текста: приложение сохранит копию файла и свяжет её с текущей песней. Текст из MIDI, вставленный вручную текст, таймкоды и незавершённые правки таблицы тоже сохраняются автоматически. Черновик после восстановления по-прежнему нужно завершить и применить кнопкой «Применить разметку».

У каждой песни свой текст и выбранная MIDI-дорожка. При открытии песни сдвиг высоты сбрасывается к `0` полутонов. Повторный импорт того же MIDI не создаёт новую запись и сохраняет его текст; изменённый MIDI считается отдельной песней, даже если имя файла совпадает.

Данные находятся в `%LOCALAPPDATA%\VocalTrainer\Songs`. Кнопка «Открыть логи и записи» на вкладке тюнера открывает папку данных приложения; внутри неё открой `Songs`. Эта папка сохраняется при обновлении `dist/Release`; исходные MIDI и LRC/TXT после импорта можно переместить. Для резервной копии закрой приложение и скопируй всю папку `Songs`.

Внутри каждой песни хранятся `track.mid`, `song.json` с привязкой и разметкой, а при импорте текста — копии исходных LRC/TXT. `selection.json` запоминает последнюю песню. Данные записываются через временный файл с заменой после успешной записи. Если сохранение не удалось, библиотека показывает сообщение; такие изменения доступны только до закрытия приложения.

Сохранение в библиотеку не требует записи голоса и не создаёт WAV. Для отдельного LRC с итоговой разметкой по-прежнему доступна кнопка «Сохранить LRC».
