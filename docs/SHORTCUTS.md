# Управление — Vocal Trainer v0.5.1

Все сочетания работают **только когда окно Vocal Trainer активно**. При наборе текста одноклавишные сочетания, Space и Enter не перехватываются. Стандартные комбинации Windows не используются.

| Сочетание | Где | Действие |
|---|---|---|
| Space | Упражнения | Начать / поставить на паузу / продолжить JSON-упражнение |
| R | Упражнения | Повторить текущую ноту |
| N | Упражнения | Пропустить текущую ноту |
| Enter | Тренажёр | Воспроизвести выбранную эталонную ноту (когда тренировка не идёт) |
| Space | Слух | Следующая пара нот |
| 1 / 2 / 3 | Слух | Выше / ниже / одинаково (ответы могут вводиться только после воспроизведения) |
| Enter | Слух | Повтор пары до ответа |
| Space | Диапазон | Начать измерение выбранной ноты |
| Space | MIDI | Начать практику (при включённом микрофоне), иначе предварительное прослушивание; пауза/продолжение |
| R | MIDI | Начать текущий фрагмент заново с тем же режимом (прослушивание или практика) |
| Enter | MIDI | Прослушать MIDI-эталон (если не идёт другое действие) |
| Esc | Любая вкладка | Прервать упражнение/MIDI/слуховое воспроизведение либо остановить обычный эталон |
| Ctrl+M | Любая вкладка | Включить/выключить микрофон |
| Ctrl+Shift+R | Любая вкладка | Начать/закончить **отдельную** запись WAV (если активен микрофон) |
| Ctrl+O | Редактор / MIDI / остальные | Импорт JSON в редактор / MIDI / обычного упражнения соответственно |
| Ctrl+S | Редактор | Проверить и сохранить JSON |
| Ctrl+1…6 | Любая вкладка | Тюнер / упражнения / слух / диапазон / редактор / MIDI |
| F1 | Любая вкладка | Настройка горячих клавиш |

## Переназначение

1. Нажать `F1`.
2. Выбрать действие в списке.
3. Нажать **Изменить сочетание**, затем нажать комбинацию на клавиатуре.
4. `Esc` отменяет захват, `Backspace` снимает назначение.
5. При конфликте (например, одинаковые клавиши в одном режиме) приложение не принимает назначение. Сохранение осуществляется сразу.
6. **Вернуть стандартные клавиши** восстанавливает всю раскладку.

Настройки: `%LOCALAPPDATA%\VocalTrainer\settings.json`. JSON имеет `schemaVersion: 1` и словарь `bindings` с объектами `{key, ctrl, shift, alt}`. Действующие назначения считываются при запуске. Если настройки повреждены, используется стандартная раскладка; исходный файл не перезаписывается до ручного сохранения.

## Пауза и данные

- При паузе JSON-упражнения или MIDI-практики логические часы останавливаются. Время, проведённое на паузе, не влияет на длительность ноты и оценку высоты.
- При паузе MIDI-прослушивания звук останавливается; при продолжении воспроизводится оставшаяся часть текущей ноты.
- Пауза не выключает микрофон, но блокирует запись измерений в оценку текущего упражнения. **Отдельная WAV-запись, если пользователь её вручную запустил, продолжает писать звук** до явной остановки.
- `R` в MIDI начинает весь выбранный фрагмент сначала, **не отдельную текущую ноту**.
- `R` в JSON-упражнении отбрасывает незавершённую попытку и повторяет ту же ноту, не расходуя лимит автоматических попыток; в логе появляется `exercise_attempt_repeated`.

## Ручная проверка на Windows

- Запустить `build.ps1 -SelfContained`, открыть EXE и проверить выбор вкладок по Ctrl+1…6.
- На вкладке «Слух» ответить `1/2/3`; проверить, что при наборе текста в редакторе эти цифры не активируют действия.
- Нажать F1, назначить другое сочетание для повтора, закрыть/перезапустить приложение; убедиться в сохранении и восстановлении по умолчанию.
- Проверить, что назначение одинаковой комбинации в двух пересекающихся областях отклоняется.
- Запустить JSON-упражнение: пауза во время звучания эталона, затем продолжение; пауза во время удержания, затем продолжение; проверить отсутствие скачка в статистике из-за паузы.
- Повторить аналогично MIDI-предпрослушивание, обратный отсчёт и MIDI-практику.
- Проверить, что `R` в JSON-упражнении повторяет **эту же** ноту, а не пропускает её; `N` — пропускает.
- Проверить Win+R и Alt+F4: системные клавиши не должны быть перехвачены приложением.

Примечание: сборка, запуск WPF, привязки и отрисовка проверены автоматически на Windows. Реальный микрофон, воспроизведение и полное занятие проверяются отдельно на используемом оборудовании.
